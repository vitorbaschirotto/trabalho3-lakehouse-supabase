# Documentação do trabalho

Bem-vindo à documentação do **Trabalho 3** (Lakehouse + Medalhão + Job).

Use o menu à esquerda para navegar:

- **Arquitetura** — visão das camadas e convenções de nome
- **Supabase** — criação das tabelas e dados de exemplo
- **Databricks** — notebooks, landing, Delta e catálogo
- **Job** — como encadear as tarefas sequencialmente

Para gerar o site localmente:

```bash
pip install mkdocs-material
mkdocs serve
```

Abra o endereço indicado no terminal (geralmente `http://127.0.0.1:8000`).
